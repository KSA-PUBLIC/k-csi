# 커뮤니티 지속가능성 통합 진단 (ver. 0.9)

한국표준협회 공공혁신센터 · 지역 진단 → K-CSI 자가진단 → 우리 활동 → 주요 타겟층 → 변화·가치 시뮬레이션

- 공개 페이지: https://ksa-public.github.io/k-csi/
- 흐름: 오픈네트워크 참석 신청 → 1 조직 정보(조직명·유형·예산·주요 대상지) → 0 지역 진단(K-CSI 2026 데이터) → 2 6대 목표(복수·순위) → 3 12대 이슈(복수·순위) → 4 핵심 셀(교집합 중 1위 추천·확정) → 5 핵심 셀 맞춤 IMP 진단(활동·성과·타겟층·소외·참여·규모·깊이·지속성·데드웨이트·귀속·리스크·중요 요소·정성 기술) · 18문항, 약 6분
- 결과지: 핵심 셀 · 변화·가치 점수 · 유형 · 육각형 모델 · 데이터 강점/취약 이슈 → 유사 사례 그룹과 임팩트 적합도 → 주요 타겟층 → 임팩트 분류 → 가장 중요한 5대 요소 → 변화이론 → 해당 SDGs → 정성적 기술 평가 → 시나리오 시뮬레이션 → 심화 진단(유료) 안내·상담 신청
- 지역 범위: K-CSI Score v4(2026)는 기초지자체 226개 시·군·구 대상. 제주특별자치도(제주시·서귀포시)와 세종특별자치시는 선택할 수 있으나 데이터 진단은 제공되지 않습니다.
- 준거: KS X ISO 37101:2016, K-CSI Score v4(2026), IMP(Impact Management Project) 5차원, 청년마을 만들기 임팩트 리포트의 변화이론·이해관계자 구조

## 파일

- `index.html` — 진단 페이지 (이 파일 하나로 동작, 서버·로그인 불필요)
- `README.md` — 이 설명

## 응답 축적

진단 시작 시 오픈네트워크 참석 신청이, 결과지 생성 시 응답·점수·응답자 정보가 그 기기(브라우저)에 쌓이며 담당자가 엑셀로 내려받습니다(관리 방법은 담당자에게 별도 안내).

### 시트 저장 · 이메일 알림

`index.html` 상단 `CONFIG.sheetEndpoint`에 담당자용 Apps Script 웹앱 주소를 넣으면, 오픈네트워크 신청과 진단 결과가 건마다 구글 스프레드시트에 쌓이고 담당자 메일로 전송됩니다. 네트워크가 끊겨도 기기에 보관했다가 연결되면 자동으로 다시 보냅니다. (설정 파일은 담당자에게 별도 제공)

## 개인정보

응답자 정보는 결과 안내·후속 상담 목적으로만 수집하며, 입력 화면에 수집 항목·목적·보유 기간을 고지하고 동의를 받습니다. 구글 시트 연동 시 시트의 공유 범위를 담당자에게만 두고, 목적 달성 후 지체 없이 파기하십시오.
