# 커뮤니티 지속가능성 통합 진단 (ver. 0.7)

한국표준협회 공공혁신센터 · 지역 진단 → 우리 활동 → 주요 타겟층 → 변화·가치 시뮬레이션

- 공개 페이지: https://ksa-public.github.io/k-csi/
- 흐름: 조직 소재지·주요 대상지 입력 → 0 지역 진단(주요 대상지 기준)(K-CSI 2026 데이터, 문항 없음) → 1 K-CSI 자가진단(6대 목표 6문항, 데이터와 비교) → 2 우리 활동(활동 유형, 직접 다루는 지역 이슈) → 2 주요 타겟층(지역 취약 이슈 × 활동으로 추천, 소외 정도·참여) → 3 규모·깊이·지속성 → 4 기여도(데드웨이트·귀속) → 5 리스크(실행·지속 장치·측정) · 19문항, 약 6분
- 결과지: 지역 진단 → 우리 활동의 위치(이슈 기여·72셀 임팩트 적합도) → 주요 타겟층 → IMP 시뮬레이션 결과(5차원 레이더·A/B/C·변화이론·사회적 가치·리스크) → 해당 SDGs → 시나리오 시뮬레이션
- 지역 범위: K-CSI Score v4(2026)는 기초지자체 226개 시·군·구를 대상으로 산출됩니다. 제주특별자치도(제주시·서귀포시, 행정시)와 세종특별자치시는 목록에서 선택할 수 있지만 데이터 진단은 제공되지 않고 K-CSI 자가진단·IMP 시뮬레이션만 진행됩니다.
- 준거: KS X ISO 37101:2016, K-CSI Score v4(2026, 226개 시군구), IMP(Impact Management Project) 5차원, 청년마을 만들기 임팩트 리포트의 변화이론·이해관계자 구조

## 파일

- `index.html` — 통합 진단 페이지 (이 파일 하나로 동작, 서버·로그인 불필요)
- `kcsi.html` — (선택) K-CSI 자가진단 30문항 단독 페이지 → https://ksa-public.github.io/k-csi/kcsi.html
- `README.md` — 이 설명

## 수정

`index.html` 상단 `CONFIG`의 `contactEmail`에 결과 수신 이메일을 넣으면 ‘이메일로 결과 보내기’의 받는 사람이 자동 지정됩니다. 응답은 응답자의 브라우저에만 저장되며, 어디에도 자동 전송되지 않습니다.
