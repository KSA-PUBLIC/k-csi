# K-CSI 자가진단 (ver. 0.3)

한국표준협회 공공혁신센터 · 커뮤니티 지속가능성 자가진단 테스트 모델

- 준거: KS X ISO 37101:2016 (6대 목표 × 12대 쟁점, 부속서 A 성숙도 매트릭스), K-CSI 측정영역 체계 (12 이슈 × 6 목표 = 72셀)
- 구성: 30문항(성숙도 5단계 척도, 약 5분) → 6대 목표 육각형 · 72셀 매트릭스 · 강점/보강 과제 · 개선 시뮬레이션 결과지
- 대상: 기초·광역지자체, 공공기관, 기업, 시민사회, 연구기관 등 범용

## 사용

이 저장소의 `index.html` 한 파일로 동작합니다. 서버나 로그인이 필요 없으며, 응답은 응답자의 브라우저에만 저장됩니다.

- 공개 페이지: https://ksa-public.github.io/k-csi/
- 결과 보관: 인쇄·PDF 저장, 결과 코드 복사, 이메일 전송

## 수정

`index.html` 상단 `CONFIG`에서 배포 주소(`siteUrl`)와 결과 수신 이메일(`contactEmail`)을 설정할 수 있습니다. 문항·매핑·산출식은 페이지의 ‘설계 노트’ 화면에 공개되어 있습니다.
