# K-CSI 자가진단 (ver. 0.4)

한국표준협회 공공혁신센터 · 커뮤니티 지속가능성 자가진단 테스트 모델

- 준거: KS X ISO 37101:2016 (6대 목표 × 12대 쟁점, 부속서 A 성숙도 매트릭스), K-CSI 측정영역 체계 (12 이슈 × 6 목표 = 72셀)
- 구성: 소속 유형별 어투의 30문항(성숙도 5단계 척도, 약 5분) → 6대 목표 육각형 · 72셀 매트릭스 · 강점/보강 과제 · 개선 시뮬레이션 결과지
- 데이터: 기준 지자체 입력 시 K-CSI Score v4(2026) 226개 시군구 데이터(종합·목표·이슈·셀)를 전국 백분위로 환산해 자가진단과 비교
- 대상: 기초·광역지자체, 공공기관, 기업, 시민사회, 연구기관 등 범용

## 사용

이 저장소의 `index.html` 한 파일로 동작합니다. 서버나 로그인이 필요 없으며, 응답은 응답자의 브라우저에만 저장됩니다.

- 공개 페이지: https://ksa-public.github.io/k-csi/
- 결과 보관: 인쇄·PDF 저장, 결과 코드 복사, 이메일 전송

## 수정

`index.html` 상단 `CONFIG`에서 배포 주소(`siteUrl`)와 결과 수신 이메일(`contactEmail`)을 설정할 수 있습니다. 문항·매핑·산출식은 페이지의 ‘설계 노트’ 화면에 공개되어 있습니다.

## K-CSI × IMP 통합 진단 ver. 0.5 (imp.html)

- 공개 페이지: https://ksa-public.github.io/k-csi/imp.html
- 흐름: 주 활동 소재지 입력 → 0 지역 진단(K-CSI 2026 데이터: Score·등급·순위·취약/강점 이슈·12 이슈 백분위, 문항 없음) → 1 우리 활동(활동 유형, 직접 다루는 지역 이슈) → 2 주요 타겟층(지역 취약 이슈 × 활동으로 추천, 소외 정도·참여) → 3 규모·깊이·지속성 → 4 기여도(데드웨이트·귀속) → 5 리스크(실행·지속 장치·측정) · 13문항, 약 5분
- 결과지: 지역 진단 → 우리 활동의 위치(이슈 기여·72셀 임팩트 적합도) → 주요 타겟층 → IMP 시뮬레이션 결과(5차원 레이더·A/B/C·변화이론·사회적 가치·리스크) → 해당 SDGs → 시나리오 시뮬레이션(취약 이슈 초점 이동·타겟 심화·지속/측정 체계·규모 확대)
- 참고: ISO 37101, K-CSI Score v4(2026), IMP(Impact Management Project) 5차원, 청년마을 만들기 임팩트 리포트의 변화이론·이해관계자 구조
